Overall Score formula

Compute overall_score as a 0–100 backend composite using percentile-style normalization and weighted blending:

Opportunity / Role block — 35%
55% opp_score
45% usage_score
Efficiency block — 35%
100% efficiency_score
Stability / Reliability block — 15%
60% stability
40% inverse volatility
Premium Role block — 15%
50% percentile of rz_tgt
50% percentile of target_share_pct
Output requirements
final overall_score should be clamped 0–100
round to whole number or 1 decimal, whichever is already standard for composite scores
if an input is missing, use best-effort normalization and avoid breaking the row
validate all TE rows contain efficiency_score and overall_score
