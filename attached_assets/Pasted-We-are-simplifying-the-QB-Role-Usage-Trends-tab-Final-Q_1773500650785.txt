Final QB trends columns should be:

1. player
2. team
3. dropbacksPerGame
4. deltaDropbacksPerGame
5. rushAttPerGame
6. deltaRushAttPerGame
7. rushTd

Goal:
This tab should compare recent QB usage vs prior usage, not show static profile/context metrics.

Please update the backend to emit the following QB trend fields:

Required output fields
- player
- team
- dropbacksPerGame
- deltaDropbacksPerGame
- rushAttPerGame
- deltaRushAttPerGame
- rushTd

Definitions
- dropbacksPerGame = current/full-sample dropbacks per game
- rushAttPerGame = current/full-sample QB rush attempts per game
- rushTd = QB rushing touchdowns in the current sample
- deltaDropbacksPerGame = recent dropbacksPerGame minus prior dropbacksPerGame
- deltaRushAttPerGame = recent rushAttPerGame minus prior rushAttPerGame

Trend window
Use:
- recent window = last 4 games
- prior window = all earlier games in the sample before those last 4 games

If fewer than 6 total games are available for a QB:
- still emit dropbacksPerGame, rushAttPerGame, rushTd
- set deltaDropbacksPerGame and deltaRushAttPerGame to null if the split sample is too small to be trustworthy

Output shape
