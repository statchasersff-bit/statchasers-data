We want to standardize Overall Score across every position’s Player Overview tab.

Goal

Add a backend-computed field called:

overall_score

to these Player Overview datasets:

rb_player_overview_2025.json
wr_player_overview_2025.json
te_player_overview_2025.json

If/when QB Player Overview exists, use the same architecture there too.

Important naming standard

Going forward, the composite stack on Player Overview should be:

opp_score
usage_score
efficiency_score
overall_score

If RB and WR still currently use player_score, keep backward compatibility only if needed temporarily, but the preferred final field is:

efficiency_score
overall_score

If easy, migrate RB and WR Player Overview rows from player_score to:

efficiency_score for the old pure-performance score
overall_score for the new blended score

If the frontend still depends on player_score, keep it temporarily as an alias of overall_score only until the frontend is updated, then remove it later.

Overall Score philosophy

overall_score should be a 0–100 blended profile score that answers:

How strong is this player’s total fantasy profile right now, relative to his position peers?

It should blend:

opportunity
role/deployment
efficiency
stability/reliability
premium/scoring-role indicators

Use percentile-style normalization within each position pool.

Clamp final outputs to 0–100.

Round to whole number for display unless there is already a composite-score convention requiring 1 decimal.

RB efficiency_score migration logic

If RB currently has no efficiency_score field and instead has player_score, split the concepts now.

Create RB efficiency_score from percentile ranks of:
yards_per_touch = 30%
explosive_run_pct = 20%
breakaway_run_pct = 20%
fpoe = 20%
stability = 10%

Then use that efficiency_score inside overall_score.

Do not let RB overall_score just equal the old player_score.

WR efficiency_score migration logic

If WR currently has no efficiency_score field and instead has player_score, create efficiency_score from percentile ranks of:

yards_per_target = 25%
catch_rate = 20%
yac_per_rec = 15%
fpoe = 20%
yards_per_route_run = 20%

Then use that efficiency_score inside overall_score.
