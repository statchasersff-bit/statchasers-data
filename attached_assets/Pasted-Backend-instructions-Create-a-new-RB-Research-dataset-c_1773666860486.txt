This table should identify RBs whose fantasy role is growing or becoming more valuable, not just who has the best season-long totals.

The goal is to answer:

Which RBs are gaining role, usage, and fantasy-relevant opportunity?

Metric definitions
Base season context

player: player name

team: team abbreviation

games: games played

snap_pct: season-to-date offensive snap percentage

touches_per_gm: (rush attempts + receptions) / games

rush_att_per_gm: rush attempts / games

targets_per_gm: targets / games

route_pct: routes run / team dropbacks, or routes on pass plays, but use one consistent definition

rz_touches: season-to-date red zone touches = red zone rush attempts + red zone receptions or red zone targets depending on available source. Preferred: rush attempts + targets inside the 20 if catch-level red zone receiving detail is not available.

goal_line_att: season-to-date rushing attempts inside the 5

Delta metric definitions

All delta fields should compare:

recent sample vs prior baseline

Preferred logic:

recent_window = last 4 games

baseline_window = previous 4 games before that

If there are not enough games:

use last 3 vs previous 3

if still not enough, use recent vs season average

if sample is too small, return null

Delta fields

delta_snap_pct = recent_snap_pct - baseline_snap_pct

delta_touches_per_gm = recent_touches_per_gm - baseline_touches_per_gm

delta_rush_att_per_gm = recent_rush_att_per_gm - baseline_rush_att_per_gm

delta_targets_per_gm = recent_targets_per_gm - baseline_targets_per_gm

delta_route_pct = recent_route_pct - baseline_route_pct

These should be signed values:

positive = role growing

negative = role shrinking

Usage & Role Score formula

This is the signature metric for the table.

Backend should calculate percentiles across RBs only and convert to a 0–100 score.

Use this formula:

Usage & Role Score =
(delta_snap_pct percentile * 0.22)
+ (delta_touches_per_gm percentile * 0.22)
+ (delta_rush_att_per_gm percentile * 0.12)
+ (delta_targets_per_gm percentile * 0.18)
+ (delta_route_pct percentile * 0.12)
+ (rz_touches percentile * 0.08)
+ (goal_line_att percentile * 0.06)
Why these weights

snap growth matters a lot

touch growth matters a lot

target growth is especially valuable in fantasy

routes help identify receiving-role gain

red zone and goal-line work add touchdown upside

Role Trend label rules

Generate a categorical label in role_trend.

Suggested rules:

Rising Fast

Use when:

delta_snap_pct >= 8

and either delta_touches_per_gm >= 2 or delta_targets_per_gm >= 1

Trending Up

Use when:

delta_snap_pct >= 4

and usage_role_score >= 65

Stable

Use when:

changes are modest and score is in middle range

Trending Down

Use when:

delta_snap_pct <= -4

or delta_touches_per_gm <= -2

Falling Fast

Use when:

delta_snap_pct <= -8

and delta_touches_per_gm <= -3

If sample is insufficient:

role_trend = "Limited Sample"

Data rules

Tell backend:

RBs only

One row per player

Use season-to-date dataset plus recent-game splits

Return null for missing values

Round:

percentages to 1 or 2 decimals

per-game rates to 2 decimals

score to 1 or 2 decimals

Counting stats stay integers where appropriate

Deltas should retain sign

Default sort should be usage_role_score descending

For percentile calculations, use a sensible minimum sample such as:

at least 3 games played

and at least 15–20 season touches

Still return players below threshold if desired, but exclude tiny samples from percentile math
