Build the full TE explorer data pipeline with 4 separate 2025-only datasets, modeled similarly to the WR tables but adjusted for TE-specific usage.

Goal

Create 4 TE-only JSON datasets for the explorer:

te_advanced_stats_2025.json
te_player_overview_2025.json
te_trends_2025.json
te_efficiency_analytics_2025.json

Store them in the same output folder pattern as the QB, RB, and WR datasets.

Position filter

Only include TE players.

General rules
2025 season only for now
no duplicate players by canonical id
percentages stored as decimals, not formatted strings
guard divide-by-zero on all rate stats
use null only when data is truly unavailable
count stats should be integers
rate stats should be rounded to sensible precision before output
each output should include a meta object with:
position: "TE"
table
season: "2025"
generated_at
columns
Dataset 1: TE Stat Explorer / Advanced Stats
Output file
te_advanced_stats_2025.json
Purpose

Broad receiving profile table for TEs:

receiving production
target role
after-catch profile
explosive plays
Required row shape
type TeAdvancedStatsRow = {
  rank: number
  player: string
  team: string
  g: number

  rec: number
  yds: number
  ypr: number | null
  ybc: number | null
  ybc_per_rec: number | null
  yac: number | null
  yac_per_rec: number | null
  brktkl: number | null

  tgt: number
  target_share: number | null
  rz_tgt: number | null

  rec_10_plus: number | null
  rec_20_plus: number | null
  rec_30_plus: number | null
  rec_40_plus: number | null
  rec_50_plus: number | null
  lng: number | null
}
Column order
[
  "rank",
  "player",
  "team",
  "g",
  "rec",
  "yds",
  "ypr",
  "ybc",
  "ybc_per_rec",
  "yac",
  "yac_per_rec",
  "brktkl",
  "tgt",
  "target_share",
  "rz_tgt",
  "rec_10_plus",
  "rec_20_plus",
  "rec_30_plus",
  "rec_40_plus",
  "rec_50_plus",
  "lng"
]
Definitions
rank = default sort rank
g = games played
rec = receptions
yds = receiving yards
ypr = yards per reception
ybc = yards before catch
ybc_per_rec = yards before catch / receptions
yac = yards after catch
yac_per_rec = yards after catch / receptions
brktkl = broken tackles on receptions
tgt = targets
target_share = team target share as decimal
rz_tgt = red-zone targets
rec_10_plus through rec_50_plus = receptions gaining at least that many yards
lng = longest reception
Default sort

Sort by:

yds desc
rec desc
tgt desc

Then assign rank.

  "role_trend"
]
Trend window logic

Use:

recent window = last 4 games
prior window = previous 4 games

If too few games:

delta fields = null
role_trend = "Insufficient Data"
Usage Score formula

Compute usage_score as a percentile-based 0–100 role score among TEs in 2025 using:

Routes/Gm = 25%
TGT/Gm = 25%
Snap % = 15%
Air/Gm = 15%
RZ TGT = 10%
End Zone TGT = 10%
Role Trend labels

Use:

Rising Fast
Trending Up
Stable
Trending Down
Falling Fast
Boom/Bust Role
Insufficient Data
Default sort

Sort by:

usage_score desc
delta_targets_per_gm desc
delta_air_yards_per_gm desc
