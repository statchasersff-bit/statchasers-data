Field definitions

Use these exact calculation rules:

rank: ordinal rank after sorting default table order
player: player display name
team: current/primary team abbreviation
g: games played
Receiving
rec: receptions
yds: receiving yards
ypr: receiving yards / receptions
ybc: yards before catch
ybc_per_rec: yards before catch / receptions
yac: yards after catch
yac_per_rec: yards after catch / receptions
brktkl: broken tackles on receptions, or best available broken tackle receiving stat from source
Targets
tgt: total targets
target_share: player targets / team total pass targets while active for the season
return as decimal in backend, for example 0.247
frontend will render as percent
rz_tgt: red-zone targets
Explosive Plays
rec_10_plus: receptions gaining 10 or more yards
rec_20_plus: receptions gaining 20 or more yards
rec_30_plus: receptions gaining 30 or more yards
rec_40_plus: receptions gaining 40 or more yards
rec_50_plus: receptions gaining 50 or more yards
lng: longest reception
Data quality rules
Use 0 for counting stats when confirmed none
Use null only when the stat truly is unavailable
Guard all rate stats against divide-by-zero
If rec = 0, then ypr, ybc_per_rec, and yac_per_rec should be null
target_share should be null only if team target denominator is unavailable
Round displayed-ready decimals in backend to 1 decimal for yardage rates:
ypr
ybc_per_rec
yac_per_rec
Keep raw decimals reasonable:
target_share: 4 decimals
Count stats should be integers
Default sorting

Default sort should be:

yds descending
rec descending
tgt descending

Then assign rank from that sorted order.
